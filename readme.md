# GLBN

Красивый локальный VPN/proxy-клиент для Windows (в духе Happ), но со своим
дизайном: анимированный фон, стеклянные карточки, 5 тем, акцентные цвета,
живые пульсации при подключении и график трафика.

## Запуск

```powershell
cd C:\Users\gariv\Desktop\vpnn
npm start
```

Или двойным щелчком по `start.bat`.

Приложение уже собрано: зависимости установлены (`node_modules`), проверки
пройдены.

## Как подключить свой прокси

1. Открой вкладку **Серверы** → **Добавить**.
2. Вставь свою ссылку: `vless://…`, `vmess://…`, `trojan://…`, `ss://…`
   (или https-ссылку подписки — она сохранится как есть).
3. Выбери сервер в списке → на главной нажми большую кнопку питания.

## Два режима работы

| Режим | Когда | Что происходит |
|---|---|---|
| **Реальный** | в Настройках указан путь к `xray.exe` | GLBN генерирует конфиг из твоей ссылки, запускает Xray и поднимает локальный SOCKS5 на `127.0.0.1:10808`. При включённом «Системном прокси» трафик Windows идёт через туннель. |
| **Демо** | путь пустой | Подключение имитируется (интерфейс, анимации, график) — без реального трафика. В интерфейсе виден бейдж «демо-режим». |

Где взять `xray.exe`: официальные релизы Xray-core (GitHub → XTLS/Xray-core,
файл `Xray-windows-64.zip`). Распакуй и укажи полный путь в Настройках.

## Что внутри

- `main.js` — окно, хранилище (JSON в `%APPDATA%\glbn`), запуск xray, пинг, системный прокси
- `preload.js` — безопасный мост main ↔ интерфейс
- `parse.js` — парсер ссылок vless/vmess/trojan/ss + сборка конфига xray
- `renderer.js`, `index.html`, `styles.css` — интерфейс
- `test-parse.js` — самопроверка парсера: `node test-parse.js`
- `shot.js` — служебный скрипт скриншотов

## Честные ограничения

- Нет TUN-режима (виртуальный сетевой адаптер) и нет авто-обновления.
- Ссылка-подписка (`https://…`) сохраняется, но её содержимое не скачивается
  и не разворачивается в список серверов — нужен конкретный сервер.
- Системный прокси — это настройка WinINET (HKCU). Некоторые приложения
  читают её только при старте: если браузер не подхватил, перезапусти его.
- График скорости в демо-режиме — имитация; в реальном режиме он показывает
  активность туннеля, точных счётчиков из Xray не снимается.
